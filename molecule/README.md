# Molecule Testing

## Installation

```bash
python3 -m venv ./molecule/venv
source ./molecule/venv/bin/activate
pip3 install -r ./molecule/requirements.txt
```

## Scenarios

### `default`

Tests the full Wazuh stack deployment on a single Ubuntu 24.04 host:

- Wazuh indexer (OpenSearch)
- Wazuh manager (SIEM engine + Filebeat)
- Wazuh dashboard (OpenSearch Dashboards + Wazuh plugin)

All three services run as Docker containers wrapped in systemd services. TLS certificates
are generated by the `wazuh-certs-generator` container during converge. Traefik is
disabled; the dashboard is exposed directly on host port 5601 for verification.

Verifies: all three systemd services are active, dashboard HTTPS endpoint responds.

## Running

Ubuntu 24.04 (default):

```bash
molecule test --scenario-name default
```

Other distributions:

```bash
# Ubuntu 22.04
MOLECULE_DISTRO=ubuntu2204 molecule test --scenario-name default

# Debian 12
MOLECULE_DISTRO=debian12 molecule test --scenario-name default
```

## Notes

Wazuh is resource-intensive. The indexer requires `vm.max_map_count=262144` and at least
512 MB of JVM heap. The verify stage waits up to 3 minutes for all services to become
healthy. Ensure the Docker host has at least 4 GB of available memory for a stable run.
